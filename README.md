## 🚀 Featured Projects

### 🕸️ [AI Criminal Network Analysis](https://github.com/Nexus-Intelligence-Labs/AI-Criminal-Network-Analysis)

🚧 **Work in Progress — Team Project**

AI/ML-powered investigative intelligence platform developed by our team for **Smart India Hackathon**. The project combines **NLP, entity resolution, relationship extraction, knowledge graphs and graph analytics** to analyze relationships across heterogeneous intelligence sources.

I serve as **Founder & Team Lead**, directing project architecture and technical direction. My direct, hands-on contributions are in **backend security, frontend development, Docker infrastructure, repository architecture and cross-team integration** — the NLP/entity-resolution/graph-analytics components were built collaboratively with AI-assisted tooling as I grow my AI/ML skill set.

**Tech:** Python, FastAPI, Neo4j, PostgreSQL, Docker, React, TypeScript, NLP & Graph Analytics

---

### 🔐 [SentinelGate](https://github.com/Ad1tya-95/Sentinel-gate)

IoT-based smart access control and security monitoring system built around the **ESP32**.

Features include **RFID + keypad authentication, FreeRTOS multitasking, Firebase real-time logging, brute-force detection, motion detection, OTA updates and security event monitoring**.

**Tech:** ESP32, C/C++, FreeRTOS, RFID, Firebase

---

### 🏦 [Mini Banking System](https://github.com/Ad1tya-95/Mini-Banking-System)

Console-based banking application developed in **C**, featuring account management, transactions, administrative functionality and persistent storage using binary file I/O.

**Tech:** C, File I/O, Data Structures

---

### 💰 [Expense Tracker CLI](https://github.com/Ad1tya-95/Expense-Tracker-CLI)

Command-line expense tracking application written in Python with **SQLite persistence** and mileage tracking functionality.

**Tech:** Python, SQLite

---

### 🍲 [Pressure Cooker Whistle Counter](https://github.com/Ad1tya-95/Cooker-Whistle-Counter)

Arduino-based embedded system that detects and counts pressure cooker whistles using a sound sensor and automates the stove shutoff process.

**Tech:** Arduino, C++, Sensors
